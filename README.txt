========================================================================
NexTerm — Professional SSH Client & Terminal Workspace (Portable Edition)
========================================================================

HOW TO RUN:
1. Double-click NexTerm.exe to launch.
2. No installation required.

NOTE ON FIRST LAUNCH (Windows SmartScreen):
Because this is an open-source / team release without an enterprise EV
certificate, Windows Defender SmartScreen may display:
'Windows protected your PC'

To proceed:
1. Click the underlined link: "More info"
2. Click the button: "Run anyway"

FEATURES:
- SSH Terminal Management with Master Vault encryption
- Locked Dark Modern workspace theme
- Multi-Tab & Split Terminal views
- Live Server Monitoring & Telemetry
- MultiExec Command Broadcast across servers
- SFTP Dual File Browser with remote editor
